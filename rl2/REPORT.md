# Does Explicit Belief Learning Improve Self-Play RL in a Card-Driven Wargame?

**Hierarchical Recurrent PPO on *Paths of Glory* — 单机 CPU 消融实验报告**

日期：2026-08-08 · 硬件：Apple M1（8 核，8GB，无 GPU）· 引擎：Rally the Troops `rules.js`（规则完备模拟器）

---

## 1. 研究问题

> **在一个卡牌驱动、部分可观测、长时程的双人零和战棋中，显式的信念学习（猜对手手牌的辅助头）能否提升自对弈 RL 的棋力？**

四臂消融：

| 臂 | GRU | Belief 辅助头 | 推理期信念采样搜索 |
|---|---|---|---|
| A | ✗ | ✗ | ✗ |
| B | ✓ | ✗ | ✗ |
| C | ✓ | ✓ | ✗ |
| D | ✓ | ✓ | ✓（复用 C 权重） |

## 2. 实验设置

**环境**：Historical 剧本，**截断至第 3 回合结束**（课程 Level 3–4，"1914 战役"）。终局用 VP 裁定：引擎自然结束按真胜负 ±1；截断时 VP>10 记 +0.6、<10 记 −0.6，另加 0.2·tanh((VP−10)/4) 的边际项（等价于 γ=1 下以 VP 为势函数的塑形，无任何行为奖励）。

**分层策略**：不枚举组合行动。引擎把每个行动天然分解为微决策序列（选牌→用途→激活→移动→战斗……），策略在每个决策点对合法候选 (动词,宾语) 打分——即引擎原生的自回归层级分解，天然自带 action mask。候选 >16 时均匀下采样。

**网络**（~50 万参数）：观测 603 维（537 全局/逐空间特征 + 65 己方手牌 one-hot + 阵营位；**不含对手手牌**）→ MLP 256→128 →（B/C）GRUCell 128 → 指针式候选打分头（候选特征 20 维：动词组 one-hot + 卡牌 OPS/SR/WS/移除/CC + 空间 VP/控制 + 单位 CF）。**特权 Critic**：独立前馈网（668 维 = 观测 + 对手真实手牌），只在训练期使用。**Belief 头**（C）：h→65 维 sigmoid，BCE 监督对手真实手牌，λ_B=0.5。

**训练**：PPO（clip 0.2，2 epochs，熵系数 0.01，Adam 3e-4，梯度裁剪 0.5），MC 优势（终局回报 − 特权价值）。每迭代 96 局自对弈（6 进程并行）；**League**：70% 当前 / 20% 历史存档（每 8 迭代入库）/ 10% 启发式 bot。JS 端推理与 torch 数值一致性经单元测试（最大误差 6e-7）。

**预算**：每臂等墙钟 **75 分钟**（含 rollout+更新+探针）。由于 GRU 开销，等墙钟≠等步数：A 完成 273 迭代（~2.6 万局），B 157，C 142。

**D 臂搜索**：仅在牌决策点，取策略 top-3 候选 × 6 次对手手牌确定化（手牌+牌库合并重洗）× 12 步廉价 rollout，以启发式评估为叶子取均值再选。

## 3. 结果

### 3.1 训练动态（健康）

三臂熵从 1.96 稳步降至 ~1.33，价值损失 0.36–0.45 → 0.08–0.20，KL 稳定在 1e-3 量级无爆炸。探针（24 局 vs 启发式）从首次的 ~50% 稳步爬升。

### 3.2 终局竞技场（每格 60 局，双边轮换执方，temp=0.3）

| 对局 | 胜-负-平 | 胜率 | VP 边际 |
|---|---|---|---|
| **A** vs 启发式 | 50-10-0 | **83%** | +3.88 |
| **B** vs 启发式 | 50-6-4 | **83%** | +3.83 |
| **C** vs 启发式 | 38-12-10 | 63% | +3.52 |
| **D** vs 启发式 | 43-12-5 | **72%** | +2.60 |
| A vs B | 30-30-0 | 50% | +0.62 |
| A vs C | 30-30-0 | 50% | +0.77 |
| B vs C | 30-29-1 | 50% | −0.12 |
| D vs C | 29-31-0 | 48% | −0.72 |
| D vs B | 30-30-0 | 50% | −0.05 |

（启发式基线 = 一步贪心 + 手工评估，即网页版曾用的对手；60 局下 ±10 个百分点内的差异不显著。）

### 3.3 信念学习质量（C 臂，**留出集** 24 局全新对局）

- BCE 0.120，平均 top-7 召回 **0.685**
- **分回合 top-k 召回**（k=对手真实手牌数）：第 1 回合 **0.427** / 第 2 回合 **0.641** / 第 3 回合 **0.559**
- 机会基线：均匀猜 65 维 ≈ **0.11**；"知道动员牌库构成"的理想随机 ≈ **0.54**（开局 7/13）

即：belief 头远超朴素基线，第 2 回合起超过牌库感知基线——它确实从公开历史中学到了"对手可能有什么牌"，符合设计意图。

### 3.4 事件时机（Event Timing）

C 臂末期自对弈中，出现"带 \* 事件可打"的 2410 个决策点里，仅 **15.2%** 选择打事件，80% 把 \* 牌烧成 OPS/SR/RP。

## 4. 结论（诚实版）

1. **管线本身成立**：75 分钟 CPU 训练即可让 50 万参数的分层递归策略以 83% 碾压手工启发式——"廉价规则模拟器 + 小网络 + 自回归微决策分解"这条路在无 GPU 条件下完全可行。
2. **GRU（B vs A）**：等墙钟下 GRU 损失约 45% 迭代量，但 B 仍与 A 打平（vs 启发式同为 83% 且败场更少，互搏 50%）。**记忆没有在 3 回合截断课程中兑现优势**——这个时程可能太短，公开历史的信息量有限。
3. **Belief 辅助头（C vs B）——研究问题的答案是"学到了，但没变强"**：猜牌头确实学到了真实信息（3.3），但在 λ_B=0.5 下 C 对启发式的胜率反而降了 20 个百分点，互搏却与 A/B 完全打平。解释：辅助梯度挤占了策略容量/迭代预算，损害了对**分布外对手**（启发式）的泛化，而对同分布 NN 对手无损。**在本预算与权重下，显式信念学习没有转化为棋力**。
4. **信念采样搜索（D）**：对启发式 +9pt（63→72%），NN 互搏 ±0。注意叶子评估用的是启发式函数（Critic 在 python 侧），这本身向搜索注入了与对手同源的知识——此增益需谨慎解读。
5. **事件时机 15.2% 不是 bug 而是截断理性**：\* 事件的回报多在远期（战争加入、牌库升级），3 回合视野下烧成 OPS 是近似最优的——**这正是课程截断偏差的直接证据**，也说明完整战役（Level 5）才是检验 card timing 的真战场。

## 5. 局限

单随机种子（无统计重复）；等墙钟而非等样本；3 回合截断改变最优策略结构（见 4.5）；候选下采样上限 16；D 的叶子评估非学习价值；启发式对手较弱，"vs 人类一般玩家"未验证；未做学派种群。

## 6. Future Work

按收益排序：① 课程推进到 Level 4–5（完整战役）重测 GRU/belief——两者的理论优势都随时程增长；② λ_B 扫描 + stop-gradient 变体（belief 只读表征不回传主干）分离"辅助任务正则化"与"梯度干扰"；③ 把特权 Critic 蒸馏为 JS 端叶子评估替换 D 的启发式叶；④ GNN 编码器利用 point-to-point 图结构；⑤ 学派种群（CP-West/CP-East/…）与 cross-play 鲁棒性矩阵；⑥ 与 NFSP/Deep CFR 风格方法对比。
